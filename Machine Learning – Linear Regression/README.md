Machine Learning – Linear Regression

This project presents the implementation of linear regression techniques. The project focuses on understanding regression from both theoretical and practical perspectives.

Overview
The work includes mathematical derivations of cost functions and gradients, as well as practical implementations of linear regression using different approaches.

Content
The project covers the following tasks:

Derivation of partial derivatives for a polynomial regression cost function

Implementation of linear regression from scratch using Python

Implementation of linear regression using PyTorch

Using scikit-learn to apply Linear, Lasso, Ridge, and Polynomial Regression

Applying the Normal Equation to compute optimal parameters

Comparing model performance using Mean Squared Error

Dataset
Different datasets are used, including provided CSV files and synthetically generated data using the make_regression function from scikit-learn.

Results
The results demonstrate how different regression methods perform in terms of accuracy and loss minimization. Visualizations of the loss function across iterations are included to analyze convergence behavior.
